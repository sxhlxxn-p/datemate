# 2023 외부 평가 v2

Proposal의 2022 학습·2023 외부 평가를 실행하는 별도 실험이다. 기존 v1.1 내부 결과와 공통 전처리 파일은 그대로 둔다. C파트, Hybrid, 커플 추천은 이 작업에 포함하지 않는다.

## 고정 규칙

설정은 `configs/external_evaluation_v2.json`에 있다.

- 2022 원본 TL/VL만으로 장소 식별과 이름·유형·주소를 구성한다. 2023 방문과 생성 시점을 알 수 없는 POI master는 2022 카탈로그에 사용하지 않는다.
- 모델 학습은 정제된 2022의 train/train_only다. TF-IDF·one-hot·장소 유사도·평균·인기 모두 이 학습 분할로만 적합한다.
- 이 별도 카탈로그에서 2022 validation으로 CBF 설정과 CF K를 다시 선택한다. 2023 평가로 설정을 바꾸지 않는다. 기존 v1.1 선택값·결과를 덮어쓰지 않는다.
- 2023 사용자의 적격 방문 중 세 번째 고유 장소를 처음 방문한 날짜를 기준일로 둔다. 그 날이 끝날 때까지의 모든 평가를 초기 입력(support)으로 사용한다.
- 기준일보다 뒤의 날짜에서 처음 입력한 장소를 제외한 새 장소만 정답(query)으로 둔다. 이후의 반복 입력 장소 방문은 버린다. 평점 평균은 support/query를 나눈 뒤 각 안에서 계산한다.
- 초기 입력 장소 3곳이 없거나, 이후 새 장소 정답이 없는 사용자는 제외하고 수를 공개한다. 성능을 보고 이 조건을 바꾸지 않는다.

## 새 사용자 점수

CBF는 2022에 학습한 변환기를 유지하고 2023 사용자의 초기 장소·평점으로 취향 벡터를 만든다. 초기 입력에만 등장한 장소는 해당 사용자가 입력한 시점의 이름·주소·유형으로 변환한다. 다른 사용자의 기록이나 query의 속성으로 보충하지 않는다.

CF는 2022 장소 간 유사도를 고정하고 새 사용자의 초기 평점을 연결한다. 2022 학습에 없는 초기 장소는 CF 계산에 쓸 수 없다. 기본 CF와 함께, 입력 장소를 제외하고 유효한 CF 후보가 전혀 없는 사용자에게만 인기순을 제공하는 `cf_or_popularity`를 별도 표시한다. 가중 결합이나 C파트의 Hybrid가 아니다.

## 후보와 지표

| 후보 모드 | 후보 |
|---|---|
| warm_2022 | 2022 학습에 등장한 장소 |
| catalog_2022 | 2022 원본으로 구성한 추천 후보 전체 |

두 모드 모두 해당 사용자의 초기 입력 장소를 제외한다. 2023 query를 보고 후보를 늘리거나 줄이지 않는다. 정답이 고정 카탈로그 밖이면 전체 지표에서 miss로 세고 수를 보고한다. 이 실험은 2023에 처음 관측된 모든 장소를 추천할 수 있다는 주장이 아니다.

평점 4점 이상을 정답으로 하는 Recall@10/NDCG@10과 추천 가능 비율·coverage를 사용한다. Warm 지표와 전체 지표는 분모를 구분한다. 정답이 있지만 모델이 점수를 못 낸 사용자는 0점으로 포함한다. 평점 예측은 전체평균 fallback 포함 값과 직접 지원한 쌍만의 값을 구분한다.

CF가 직접 예측할 수 있는 정답 쌍에 한정한 보조 비교도 저장한다. 이때 다른 모델도 정확히 같은 쌍·후보를 사용한다. 이 작은 부분집합의 성능을 전체 결과 대신 사용하지 않는다.

## 실행

Python 3.11과 고정 requirements를 사용한다.

```sh
python scripts/external_evaluation.py --stage prepare --raw-dir "/path/to/raw/data"
python scripts/external_evaluation.py --stage tune
python scripts/external_evaluation.py --stage evaluate
```

데이터는 `outputs/proposal_external_v2/data/`, 선택 설정은 `outputs/proposal_external_v2/frozen_settings.json`, 집계 결과는 같은 폴더의 summary.json에 저장한다. 모델별 결과는 `outputs/experiments/external_v2/`에 저장한다. 모든 행 단위 파일은 로컬 전용이다.

선택 설정에 데이터·코드·규칙 해시를 함께 저장한다. 변경된 데이터로 평가하려 하면 거부한다. prepare가 원본 폴더 아래에 결과를 쓰는 것도 거부한다.

2022 연말까지 관측한 장소 속성을 쓰는 평가이며, 원천 로그에 별도의 속성 수정 시각은 없다. 실제 당시 서비스의 카탈로그를 완벽히 재구성했다고 주장하지 않는다. v1.1과 후보·정제 조건이 달라 수치를 직접 섞어 비교하지 않는다.
