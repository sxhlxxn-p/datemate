# 재현 및 업로드 검증 기록

확인일: 2026-10-29. 기존 로컬 term project의 원본과 Git 작업 상태를 보존하기 위해 인접한 datemate-team 폴더에 검토된 파일만 복사하여 독립 저장소로 구성했다. 기존 저장소는 커밋 1개, 리모트 없음, 수정 중인 문서 및 스크립트가 있었다. 기존 Git 이력과 제안서/보고서의 PDF·Word 원본은 전송 대상에서 제외했다.

## 실제 실행 결과

- 실제 원본 약 8.5GB, ZIP 약 2.04GB는 로컬에만 보관.
- 원본 acquisition manifest의 CSV 89개 경로·바이트 크기 검사 통과. 이 manifest는 최초 확보 배치 전체라 중복 TS/VS도 포함한다. builder는 TL/VL과 POI master만 사용하므로 중복 파일이 없는 별도 배치에서는 manifest 검사 실패와 builder 실행 가능 여부를 구분한다.
- 전체 POI master를 읽는 공통 전처리를 다시 실행했다. 빠른 skip 모드가 아니다.
- 상호작용 29,485행, 28,527 사용자–장소 쌍, 상호작용 사용자 6,031명. users.csv는 상호작용이 없는 프로필도 포함하여 총 6,480행이다.
- 장소 34,671개, 후보 16,764개, 공통 모델 장소 1,609개.
- train 14,010행 / train_only 10,260행 / validation 2,600행 / test 2,615행.
- 기존 산출물과 새 산출물의 interactions.csv, places.csv, users.csv, source_inventory.csv SHA-256이 모두 일치했다. 상세 해시는 reports/reproduction_checks.json에 있다. 생성 시각과 로컬 경로가 포함된 quality_report 전체는 공유하지 않는다.
- 실제 산출물의 기본키, 참조 무결성, 평점 범위, 사용자–장소 분할 분리, train_only, warm-item 플래그 검증 통과.
- 가상 원천 생성 → 공통 전처리 → 검증 통과: 20개 상호작용, 6개 장소, 4개 사용자.
- 반복 방문 분할 유지와 의도적으로 주입한 사용자–장소 분할 누수의 거부 테스트 통과.

## 범위와 한계

모델은 구현·학습·평가하지 않았다. 평가 절차와 설정은 후속 CBF/CF/Hybrid 구현의 공통 계약이다. 전체기간 장소 카탈로그를 활용하는 기존 전처리의 한계는 evaluation.md에 명시했다. 이것을 엄격한 미래 정보 차단 성능으로 해석하지 않는다.

업로드 검사는 코드·문서 allowlist의 파일 목록, 파일 크기, 자격증명/연락처 패턴, 제외 경로를 확인한다. 패턴 검사는 모든 민감정보의 부재를 수학적으로 보장하지 않으므로 실제 레코드 파일과 바이너리 문서를 애초에 포함하지 않는다. 새 저장소에는 과거 이력을 가져오지 않는다.
