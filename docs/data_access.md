# 데이터 출처와 접근 조건

확인일: 2026-10-29. 출처는 AI-Hub 국내 여행로그 데이터(수도권) 2022·2023이다. 저장소에는 데이터 레코드를 포함하지 않는다.

AI-Hub 공식 FAQ는 데이터 원본 및 단순 가공 형태의 외부 공개·공유·재배포를 허용하지 않는다고 안내한다. private GitHub도 데이터 공유 허가를 대신하지 않는다. 각 팀원이 해당 데이터 이용을 신청·승인받고 직접 다운로드한다. 파일별 추가 조건과 정의서는 다운로드 시점에 다시 확인한다. 개별 데이터의 별도 재배포 허가를 확보한 상태는 아니다.

- 공식 FAQ: https://www.aihub.or.kr/aihubnews/faq/list.do
- 공식 데이터 검색: https://www.aihub.or.kr/ 에서 “국내 여행로그 데이터(수도권)”의 2022·2023 버전을 확인.

원본 CSV, 단순 가공 CSV, 여행객·방문 기록, 주거·이동 좌표, 프로필, ID 매핑, 예측 레코드, 학습 모델은 로컬에 둔다. 연도 접두어나 장소 해시는 익명성 또는 재배포 허가를 보장하지 않는다. 다운로드 키·로그인 정보는 저장소나 터미널 기록에 입력하지 않는다. 이 프로젝트의 오프라인 builder에는 API 키가 필요 없다.

출처 표기는 보고서/발표에서 정식 데이터명, AI-Hub, 구축 지원기관을 명시하고 공식 안내 문구를 확인한다. 공유 가능한 산출물은 코드, 직접 작성한 문서, 레코드 없는 파일명·스키마·크기 manifest, 집계 통계다. 소규모 하위집단의 민감 통계도 추가 검토 없이 공유하지 않는다.
