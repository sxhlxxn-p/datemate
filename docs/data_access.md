# 데이터 이용 안내

사용 데이터는 AI-Hub 국내 여행로그 데이터(수도권) 2022·2023이다. 각자 이용 신청·승인 후 직접 다운로드한다.

AI-Hub 공식 FAQ에서는 원본과 단순 가공 데이터의 외부 공유·재배포를 제한하고 있다. Private 저장소에도 CSV를 올리지 않는다. 파일별 추가 이용 조건은 다운로드할 때 확인한다.

- [AI-Hub 데이터 검색](https://www.aihub.or.kr/)
- [공식 FAQ](https://www.aihub.or.kr/aihubnews/faq/list.do)

저장소에는 코드·설정·문서와 집계 통계만 공유한다. 사용자 프로필, 방문 기록, ID 매핑, 개인별 예측과 모델 파일은 로컬에 둔다. 연도를 붙인 사용자 ID도 원본 식별자와 연결되므로 그대로 공개하지 않는다. 전처리 스크립트에는 API 키가 필요 없다.

보고서와 발표에는 정식 데이터명과 AI-Hub 출처를 표기하고, 지원기관 표기는 공식 안내를 따른다. 코드에 별도 오픈소스 라이선스는 부여하지 않았다.

이용 안내 확인일: 2026-10-29.
