# Contextual Bandit 확장 실험

기존 CBF·CF·Hybrid 실험과 별개로, 커플 추천 전략을 피드백으로 선택하는 bandit을 추가했다. **실제 여행로그나 사용자 피드백을 사용하지 않은 가상 환경 실험**이다. 기존 오프라인 성능과 합쳐 해석하지 않는다.

## 조건

네 행동은 CBF/Hybrid 각각의 평균·최솟값 결합이다. 세 환경, 20개 seed, seed별 학습 3,000회와 분리된 평가 1,000회를 사용했다. 후보 40개 중 5개를 추천한다. epsilon=0.1, 합성 Hybrid alpha=0.4를 사전 고정했으며 결과를 보고 재튜닝하지 않았다. 맥락 8개 segment에 독립적으로 보상 평균을 학습하는 epsilon-greedy 정책과 맥락을 무시한 동일 정책을 비교했다.

평가에서는 학습을 멈췄다. 정책마다 같은 가상 입력과 행동별 피드백을 사용하되, 학습에는 선택한 행동의 피드백만 전달했다. 보상은 두 사용자의 잠재 수락 확률로 생성한 공동 수락 여부다. 모델 점수 자체를 보상으로 삼지 않았다. 이 잠재 수락 확률은 가상 환경에서만 알 수 있다.

## Paired 비교

동일 seed의 `Contextual − 고정 Hybrid 평균` 기대 보상 차이다. 구간은 20개 seed의 paired 차이를 5,000회 bootstrap한 95% 구간이다. 실제 사용자 모집단의 신뢰구간으로 해석하지 않는다.

| 환경 | 차이 | Seed bootstrap 95% 구간 |
|---|---:|---:|
| informative | -0.0078 | [-0.0108, -0.0052] |
| noisy | -0.0081 | [-0.0107, -0.0056] |
| uninformative | -0.0004 | [-0.0011, +0.0004] |

## 해석

- informative/noisy에서는 무작위 선택보다 기대 보상이 높지만, 고정 Hybrid 평균 결합보다 낮다. 학습이 불필요한 강한 고정 전략을 이겼다는 근거가 없다.
- 맥락 없는 bandit 대비 차이의 seed bootstrap 구간은 세 환경 모두 0을 포함한다. 현재 8개 segment를 사용한 추가 이득도 명확하지 않다.
- uninformative에서는 무작위 대비 차이의 구간도 0을 포함한다. 점수가 선호와 무관하면 전략을 바꾸는 것만으로 품질을 개선하기 어렵다.
- 이 환경의 보상 정의·잡음·정상적인 사용자 분포에 한정된 결과다. 각 회는 독립 사용자 쌍이므로 동일 커플의 장기 취향 변화나 장기 보상은 평가하지 않았다.
- 네 전략 중 선택하는 학습 모듈과 기존 커플 점수 배열을 받는 연결 함수까지 구현했다. 실제 서비스 피드백 수집이나 온라인 운영은 하지 않았다.

## 재현과 검증

```sh
python scripts/run_bandit_simulation.py
python -m unittest discover -s tests -v
```

실행 환경은 집계 JSON의 Python·NumPy 버전, 설정과 코드 SHA-256으로 남겼다. 기존 37개를 포함한 42개 테스트가 통과했다. 선택 확률의 합·탐색 확률 하한, 선택 피드백만 갱신, 평가 중 갱신 금지, 재현성, 두 사용자 방문 제외와 기존 mean/min 연결을 확인했다. 가상 이벤트의 행동·선택 확률·관측 보상은 로컬 `outputs/bandit_simulation/synthetic_events.csv`에 저장한다. 저장소에는 코드·설정·집계만 올린다.

설정·가상 보상 가정·실제 점수 연결 방법은 [사용 안내](../docs/contextual_bandit.md)를 참고한다. 이번 결과는 강화학습으로 실제 추천 정확도나 커플 만족도가 개선됐다는 근거가 아니다.
