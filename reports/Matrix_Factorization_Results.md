# Matrix Factorization 확장 평가

Proposal의 선택 확장인 명시적 평점 MF를 구현하고, 2022 내부 평가와 2022→2023 신규 사용자 외부 평가를 완료했다. 기존 CBF·Item-KNN CF·Hybrid 결과와 Bandit 시뮬레이션은 별도로 유지한다.

## 방법과 설정 선택

관측된 평점만으로 전체 평균·사용자 편향·장소 편향·잠재 벡터 내적을 학습했다. 미방문 쌍을 0이나 부정 응답으로 채우지 않는다. L2 정규화가 있는 alternating ridge least-squares로 20회 반복했다.

두 사전 조건 각각 2022 warm validation NDCG@10 warm으로 차원 8·16 × 정규화 0.1·1·10을 비교했다. 두 조건 모두 차원 8, 정규화 10이 선택됐다. 차원 16·정규화 10과 validation 점수가 같아 작은 차원 우선 규칙을 적용했다. Test나 2023 결과로 재튜닝하지 않았다. 전체 grid와 손실은 [집계 JSON](mf_summary.json)에 있다.

## 2022 내부 평가

기존 공통 평가 v1.1과 데이터·후보·정답 쌍·positive 사용자 해시가 일치했다. 기준선 3개의 기존 지표가 정확히 재현되는 것도 확인했다. 아래 CBF·CF·Hybrid는 [기존 최종 평가](Final_Model_Evaluation.md)의 참조값이며, MF와 기준선은 이번 코드에서 새로 실행했다. 기존 평가는 Python 3.13, 이번 MF는 Python 3.11이며 패키지는 같은 고정 버전이다. 기존 모델·평가 코드는 변경하지 않았다.

### Warm 후보·warm 정답 사용자 570명

후보 7,172개, Top-10이다. 이 표는 `recall_at_10_warm`, `ndcg_at_10_warm`을 사용한다.

| 모델 | Recall@10 | NDCG@10 |
|---|---:|---:|
| 인기순 | 0.075439 | 0.039588 |
| CBF(region) | 0.042105 | 0.019282 |
| Hybrid α=0 | 0.042105 | 0.019282 |
| Item-KNN CF K=40 | 0.029825 | 0.015557 |
| MF | 0.024561 | 0.010784 |

### 전체 후보·관련 정답 사용자 1,069명

고정 후보 16,764개다. Cold item 정답도 분모에 남긴다.

| 모델 | Recall@10 | NDCG@10 | Top-10 제공 비율 |
|---|---:|---:|---:|
| 인기순 | 0.040225 | 0.021109 | 100.0% |
| CBF(region) | 0.020580 | 0.011580 | 100.0% |
| Hybrid α=0 | 0.020580 | 0.011580 | 100.0% |
| Item-KNN CF K=40 | 0.015903 | 0.008295 | 81.3% |
| MF | 0.013096 | 0.005750 | 100.0% |

MF의 순위 성능은 인기순·CBF·기존 CF보다 낮았다. MF는 학습 장소 사이에 직접 공통 이웃이 없어도 점수를 낼 수 있어 내부 평가의 Top-10 제공 비율은 100%였다. 그러나 평가기가 방문을 제외한 학습 장소만 실제로 점수화할 수 있으며 cold item을 추천할 수는 없다.

### 평점 예측

전체 test 1,243쌍을 동일 분모로 비교했다. MF가 직접 예측한 쌍은 645개이며 나머지는 공통 평가기가 학습 평균으로 대체했다.

| 모델 | 전체 MAE | 전체 RMSE | 직접 예측 쌍 |
|---|---:|---:|---:|
| 전체평균 | 0.664282 | 0.802577 | 1243 |
| 장소평균 | 0.700955 | 0.880632 | 645 |
| MF | 0.636658 | 0.783239 | 645 |

전체평균보다 평점 오차는 줄었지만 순위 개선으로 이어지지 않았다. 지원 가능한 동일 정답 쌍에 한정한 기준선 비교도 JSON에 별도로 남겼다.

## 잠재 벡터 기여 진단

강한 정규화가 선택돼 잠재 벡터의 기여를 추가 검사했다. 같은 설정으로 재학습한 뒤 factors=0·reg=10의 편향 모델과 비교했다. 내부 평가 모델의 train 쌍에서 잠재 내적 절댓값 최댓값은 약 `3.06e-16`, 같은 정규화의 편향 모델과 예측 차이는 최대 `1.78e-15`였다. 외부 평가용 학습에서도 같은 현상이 나타났다.

따라서 선택된 MF는 사실상 정규화된 편향 모델처럼 동작했다. 이번 평점 오차 감소를 잠재 요인 학습의 효과로 주장하지 않는다. 별도로 저장한 reg=1 편향 진단과의 차이도 정규화 차이를 포함한다. 잠재 요인이 유용하지 않다는 일반 결론이 아니라, 이번 관측 데이터·후보 grid에서 추가 이득이 확인되지 않았다는 결과다.

## 2022→2023 신규 사용자 외부 평가

2022 전용 장소 사전을 사용한 external_v2를 따른다. 초기 입력만으로 신규 사용자 벡터·편향을 추정하고, 전체 평균·장소 벡터·장소 편향은 고정했다. 학습 장소가 초기 입력에 없으면 MF는 해당 사용자를 지원하지 않는다. 추천 불가 사용자만 인기순으로 전환하는 정책도 별도로 평가했다.

589명 중 관련 정답이 있는 574명, 관련 정답 1,996쌍을 분모로 한다. warm 후보 7,116개와 catalog 후보 9,747개의 아래 순위 결과는 같았다. MF가 cold item 점수를 낼 수 없기 때문이다. 전체 사전 밖 관련 정답은 기존과 같은 1,777쌍이다.

| 모델 | Recall@10 | NDCG@10 | Top-10 제공 비율 |
|---|---:|---:|---:|
| 인기순 | 0.000884 | 0.000714 | 100.0% |
| MF | 0.000705 | 0.000681 | 35.2% |
| MF / 점수 없으면 인기순 | 0.000705 | 0.000681 | 100.0% |

전체 정답 2,318쌍 중 MF 직접 예측은 103쌍이다. 전체평균 대비 전체 MAE는 0.675215 → 0.673596, RMSE는 0.798058 → 0.797117였다. 평균 대체가 포함되므로 이를 신규 사용자 직접 예측 성능으로 해석하지 않는다. 전체 MF-supported 정답 부분집합과 모든 모델의 동일 부분집합 평가도 JSON에 있다.

외부 평가에서 순위 개선은 확인되지 않았다. 사용자 단위 인기순 전환은 제공 비율을 늘렸지만 정확도를 개선하지 않았다. 이 결과는 2023으로 새로 학습한 연도 내 실험과 구분한다.

## 재현·검증

실행 방법은 [MF 안내](../docs/matrix_factorization.md)를 따른다. `python scripts/audit_mf_latent.py`는 동결된 두 모델을 다시 적합해 같은 정규화의 편향 모델과 잠재 기여를 진단한다. 이 진단으로 파라미터를 재선택하지 않는다.

48개 테스트가 통과했다. 목적함수 감소, 관측치만 학습, holdout 변경에 대한 학습 불변, fold-in의 ridge 해와 장소 벡터 고정, 미지원 사용자·장소, 방문 제외, 내부·외부 가상 전체 실행, 입력 변경 시 평가 거부를 확인했다. 기존 결과는 덮어쓰지 않았다.

평가 소스 커밋과 파일 해시는 JSON에 기록했다. 로컬 중복 파일과 작성 중 문서 때문에 Git dirty=true가 기록됐으며 이를 clean 실행으로 표시하지 않는다. 실제 학습·평가 소스와 데이터는 튜닝 시 동결한 해시로 일치 여부를 검사했다. 원본·전처리·개별 예측은 저장소에서 제외한다.
