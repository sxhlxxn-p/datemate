# DateMate 최종 모델 평가

2026-11-02, 공통 평가 v1.1의 분할·후보·지표를 유지한 상태에서 기준선·CBF·CF·Hybrid를 같은 clean 커밋과 같은 데이터로 다시 실행했다. 2022 known-user test를 최종 모델 비교로 사용하고, 2023 연도 내 Hybrid test와 2022→2023 신규 사용자 외부 평가는 별도로 해석한다.

## 비교 조건

- 소스 커밋: `ce0d136151adf1e4fff298300b2e35cd0687523d`, dirty=false
- Python 3.13.13 / pandas 2.2.3 / numpy 2.2.6 / scipy 1.15.3 / scikit-learn 1.6.1
- 학습: `train + train_only`, 튜닝: `validation`, 최종 평가: `test`
- 정답: 평점 4점 이상, Top-10, 사용자의 학습 방문 장소 제외
- 2022 test: 전체 1,243명, 관련 정답 사용자 1,069명, warm 정답 사용자 570명
- 후보: warm 7,172곳, all 16,764곳
- 데이터 SHA-256: interactions `494fb0e…`, places `485504f…`, users `6e1738a…`

같은 후보 모드 안에서 모든 모델의 데이터·후보·평가 쌍·positive 사용자·Git 커밋 해시와 사용자 분모가 일치하는지 자동 검사했다. 행 단위 예측과 원본 데이터는 `outputs/`에만 두고, 저장소에는 집계 결과만 남긴다.

## 2022 최종 test

Warm 표는 warm 후보와 warm 정답 570명을 기준으로 한다.

| 모델 | Recall@10 | NDCG@10 | 추천 가능 비율 | Item coverage |
|---|---:|---:|---:|---:|
| 인기순 | **0.075439** | **0.039588** | 1.0000 | 0.0020 |
| CBF(region) | 0.042105 | 0.019282 | 1.0000 | 0.4905 |
| Hybrid, α=0.00 | 0.042105 | 0.019282 | 1.0000 | 0.4905 |
| Item-KNN CF, K=40 | 0.029825 | 0.015557 | 0.8129 | 0.4088 |
| 전체평균 / 장소평균 | 0 | 0 | 1.0000 | 0.0015 |

All 표는 고정 전체 후보와 관련 정답 사용자 1,069명을 기준으로 한다.

| 모델 | Recall@10 | NDCG@10 | Warm NDCG@10 | 추천 가능 비율 |
|---|---:|---:|---:|---:|
| 인기순 | **0.040225** | **0.021109** | **0.039588** | 1.0000 |
| CBF(region) | 0.020580 | 0.011580 | 0.003415 | 1.0000 |
| Hybrid, α=0.00 | 0.020580 | 0.011580 | 0.003415 | 1.0000 |
| Item-KNN CF, K=40 | 0.015903 | 0.008295 | 0.015557 | 0.8129 |
| 전체평균 / 장소평균 | 0 | 0 | 0 | 1.0000 |

2022 Hybrid는 validation에서 α=0.00이 선택됐다. 점수 구현도 α=0일 때 CBF 값을 그대로 반환하며, 두 후보 모드의 네 랭킹 지표가 CBF(region)와 오차 `1e-15` 이내로 같은지 검사했다. 따라서 2022에서는 Hybrid 결합의 추가 이득이 확인되지 않았다. 인기순이 정확도는 가장 높지만 item coverage가 매우 낮아 모든 사용자에게 거의 같은 장소를 제시한다.

## 2023 연도 내 Hybrid

Validation에서 α=0.40을 선택한 뒤 같은 값을 고정해 test를 평가했다.

| 분할 | 후보 | Recall@10 | NDCG@10 | Warm NDCG@10 |
|---|---|---:|---:|---:|
| validation | warm | 0.051625 | 0.026404 | 0.055795 |
| test | warm | 0.025257 | 0.011514 | 0.026244 |
| validation | all | 0.049713 | 0.022258 | 0.029189 |
| test | all | 0.027128 | 0.013011 | 0.014521 |

2023에서는 CBF와 CF가 실제로 결합됐지만 test가 validation보다 낮다. 이 결과만으로 Hybrid의 일반적 우위를 주장하지 않는다. 2023 데이터로 다시 학습·튜닝한 연도 내 실험이므로 2022 모델의 외부 일반화 성능도 아니다.

## Cold item과 외부 평가

2022 test의 관련 정답 1,069개 중 499개가 학습 후보 밖 cold item이다. Warm 평가는 모든 모델이 점수를 낼 수 있는 공통 조건의 비교이고, all 평가는 CBF의 cold-item 점수 가능성과 전체 정답 손실을 함께 본다. 다만 all 후보는 두 연도 로그를 통합한 고정 카탈로그여서 실제 추천 시점의 카탈로그로 해석하지 않는다.

별도의 2022→2023 신규 사용자 외부 평가에서는 관련 정답 1,996쌍 중 1,777쌍(89.0%)이 2022 카탈로그 밖이었다. CBF·CF·기준선만 평가했고 Hybrid는 포함하지 않았다. 외부 평가와 2023 연도 내 Hybrid 결과는 후보·학습·사용자 조건이 달라 한 표에서 직접 비교하지 않는다.

## 결론과 발표 기준

1. 최종 정확도 기준선은 인기순이다. 개인화 모델이 이를 넘었다고 주장하지 않는다.
2. 지역 특성을 넣은 CBF가 2022에서 CF보다 높고, 추천 다양성은 인기순보다 크다.
3. 2022 Hybrid는 CBF endpoint, 2023 Hybrid는 실제 결합이지만 held-out 개선 근거는 제한적이다.
4. CF는 데이터 희소성 때문에 점수 제공 비율과 직접 지원 평점 쌍이 적다.
5. 커플 평균·최솟값 결과는 공동 만족도 정답이 없는 기능 시연이며 성능 평가가 아니다.
